COMPUTER BASICS

Inside a Computer

A computer is an electronic device that receives data, processes it, stores information and produces useful results. Computers are used in education, business, science, communication and entertainment.

  • Desktop computers are designed for desks and workspaces.
  • Laptops are portable computers with built-in screens.
  • Tablets provide touchscreen computing.
  • Servers provide services and information to other computers.
IMPORTANT COMPONENTS

Computer Hardware

Each computer component has a specific job. They work together to run applications and process information.

PROCESSING

CPU

The Central Processing Unit executes instructions and performs calculations. It is often described as the brain of a computer.

MEMORY

RAM

Random Access Memory temporarily holds information that programs are currently using. Its contents are lost when power is switched off.

STORAGE

SSD and HDD

Storage devices keep your files, operating system, applications, photographs and documents even when the computer is off.

GRAPHICS

GPU

The Graphics Processing Unit handles visual calculations and helps display images, videos and 3D graphics.

CONNECTIONS

Motherboard

The motherboard connects major components and allows them to communicate with one another.

INPUT

Peripherals

Keyboards, mice, monitors, microphones and printers help users interact with computers.

DID YOU KNOW?

Hardware and software work together.

Hardware means the physical parts of a computer. Software means the programs and instructions that tell the hardware what to do. Neither is enough on its own for a fully useful computer system.
